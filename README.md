# 译林六上 · 英语刷题台

译林版（三起）六年级上册（2024 版）英语刷题网页合集。**单文件、离线可用、手机浏览器直接打开**，不需要安装，不需要登录。

## 在线使用

开启 GitHub Pages 后：`https://你的用户名.github.io/仓库名/`

也可以直接下载 `index.html` 等文件，用浏览器打开。

## 四个入口

| 页面 | 文件 | 内容 |
|---|---|---|
| 单词默写 | `danci.html` | 154 词 + 115 短语，五种题型随机混（英译中选 / 中译英选 / 英译中输入 / 中译英输入 / 填空补全），30 秒倒计时、美式发音、内置英文键盘、词汇表（点词看释义与搭配）、多用户排行榜 |
| 语法与真题 | `lianxi.html` | U1–U8 单元知识库（词汇 / 短语 / 句型 / 语法 / 易错），76 道 U2–U3 拔高卷原题，18 类考点无限变式，错题本，讲评台 |
| 语法刷题 | `yufa.html` | 232 题，按单元 / 整卷 / 专项分组，写完立刻出考点与解析，可一键重做错题 |
| 变式题工厂 | `bianshi.html` | 选一个考点，机器每次换主语、换时间、换动词出新题；「再来一道同考点」练到不错为止 |

## 怎么改内容

- **单词**：改动 `danci.html` 里的 `WORD_DATA`（`themes → lessons → words/phrases`），或重新用 `vocab-quiz-builder` 生成。
- **语法题 / 知识点**：改动对应 HTML 里的 `QUIZ` / `UNITS` / `BANK`，字段见文件开头的注释。
- 三个页面都是自包含的，改完存盘刷新即可，无需构建。

## 数据与隐私

所有作答记录存在浏览器 `localStorage` 里，只在这台设备上，不上传任何服务器。换设备请用页面内的「导出 / 导入」搬数据。
